Reference: GSAP 3.15.0 · API review October 21, 2026. Examples pin this version for repeatability. SplitText’s rewritten API requires 3.13+; context and matchMedia require 3.11+. Plugins are separate imports/scripts; each example labels its dependencies. GSAP 3.13+ makes all plugins available through public npm, subject to the GSAP standard license. The license page was temporarily unavailable during verification; this handbook does not interpret its terms.

How to run the code: the first example is a complete HTML document. Other body.html examples are independent body fragments with their own styles, core script, and required plugin scripts; place one in a basic HTML document and serve it locally. Do not combine all examples on one page. Module, TypeScript, React, and test fixtures have explicit setup labels. Code is displayed and copied; it is never executed by this handbook.

Early demonstrations isolate an API and may animate on load. When adapting them to production, apply the responsive, reduced-motion, lifecycle, and accessible-state patterns from Chapters 12 and 21–27. Content and essential actions must remain usable when motion is disabled.

These are learning stages, not an assessment of your present ability. You can be productive before mastering every plugin.

The six areas of mastery

  • GSAP Core — Tweens, timelines, easing, staggers, and animation control.
  • Scroll Animations — ScrollTrigger, ScrollSmoother, and complex scrolling experiences.
  • Advanced Animation — SVG, text, FLIP, interactive effects, and plugins.
  • Animation Engineering — Performance, accessibility, responsive behavior, and architecture.
  • Framework Integration — Vanilla JavaScript, TypeScript, React, and Next.js.
  • Motion Design — Timing, choreography, storytelling, and creating polished experiences.

Suggested schedule

Allow roughly 5–7 focused hours per week, including projects. The schedule is a study structure, not a promise of expertise.

Period Focus Topics
Weeks 1–3 Core foundations Tweens, CSS properties, easing, staggers, and callbacks
Weeks 4–6 Animation coordination Timelines, playback controls, reusable functions, and UI interactions
Weeks 7–10 Scroll animation ScrollTrigger, pinning, scrubbing, responsive behavior, and parallax
Weeks 11–15 Creative techniques Text, SVG, FLIP, Draggable, and advanced plugins
Weeks 16–20 Production engineering Performance, cleanup, accessibility, TypeScript, and React
Beyond week 20 Specialization and mastery Complex portfolio projects, motion design, and advanced architecture

Recommended development path

  1. Master GSAP Core and Timelines using vanilla JavaScript.
  2. Learn ScrollTrigger deeply and build two complete animated landing pages.
  3. Add text, SVG, and FLIP animations to your projects.
  4. Refactor your animations into reusable TypeScript modules.
  5. Integrate GSAP into React once you're comfortable with React's component lifecycle.
  6. Focus on production performance, accessibility, and animation architecture.

Practice and visual problem-solving matter as much as API recall. Prefer a useful, accessible, maintainable result over adding another effect.

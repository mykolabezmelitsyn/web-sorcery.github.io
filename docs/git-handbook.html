Git commands by task
Run commands inside your repository unless starting or cloning one. Replace <placeholders> with your values; [brackets] mark optional arguments and | marks alternatives. Examples are independent. HEAD is the current commit; origin is a remote name. Check git status before changing work. switch and restore require Git 2.23+; config set/list require Git 2.46+ (older forms: git config --global key value and git config --list --show-origin).

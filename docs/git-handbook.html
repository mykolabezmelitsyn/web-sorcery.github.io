Learn the model before memorizing commands.

Follow stages 1–4 for foundations, prioritize 5–10 for everyday collaboration, then deepen your knowledge in 11–17. Stage 18 applies the skills to frontend work. Every roadmap topic, essential command, practice prompt, project, and study-plan item is retained below.

Version baseline: lab scripts tested with Git 2.52.0. This is a tested baseline, not a claim about the latest release. switch/restore need Git 2.23+; init -b needs 2.28+. Newer config get/set/list forms need 2.46+; examples use older compatible forms. Consult git help COMMAND for your installed version.

Running examples: POSIX-style shell (macOS/Linux or Git Bash on Windows), with mktemp. PowerShell needs syntax adaptations. Each complete lab creates a fresh temporary directory and sets repository-local identity. Contextual snippets require the stated branches/files and are independent alternatives. Code is never executed by this page.

Before a command, ask: what happens to my working tree, index, local refs, and remote refs? Preserve valuable uncommitted work separately. Recovery has limits, particularly for discarded files Git never recorded.

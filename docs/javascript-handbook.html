This handbook follows all 436 topic bullets in javascript-mastery-roadmap.md, in their original order. It assumes basic HTML/CSS familiarity and develops JavaScript from revision through advanced browser engineering. Prioritize vanilla JavaScript, async work, browser APIs, and reusable UI architecture before optional specializations.

Examples are independent. Core examples are ES modules using established modern syntax, including ES2023 features such as toSorted; use a current supported browser or the labeled Node runtime. Browser examples need a DOM and should be served over localhost. A multi-file example keeps the shown filenames together. Tool, backend, and integration requirements are labeled; they are not interchangeable runtimes.

Read the explanation, run an example, then complete its checkpoint. Project code supplies focused starters rather than five finished applications. Code is displayed and copied, never executed by the handbook. APIs with compatibility or security-context requirements have notes, and tool-specific examples state a reference major version. Reference review: October 22, 2026.

The roadmap’s starting point is intermediate, but it does not measure your ability. Levels and any self-assessment selections are learning aids, not a certification.

Recommended learning order

Priority Topics Why
1 — Highest Closures, this, objects, array methods Strengthen core JS knowledge
2 — Highest DOM, events, browser APIs Directly useful in your daily front-end work
3 — Highest Promises, async/await, Fetch, event loop Essential for modern asynchronous applications
4 — High Classes, prototypes, modules, architecture Build reusable libraries and maintainable components
5 — High Testing, debugging, performance Develop production-level engineering skills
6 — High TypeScript and React integration Support your transition to modern front-end development
7 — Medium Advanced internals, algorithms, metaprogramming Develop deeper language expertise
8 — Optional Engine internals, ASTs, binary data Pursue specialized JavaScript knowledge

TypeScript and React integration are a later priority in the roadmap. Build a strong JavaScript model first; use the TypeScript handbook and GSAP handbook when those integrations become useful. You do not need every optional specialization to become an expert frontend developer.

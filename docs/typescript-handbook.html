Build a solid foundation, write dependable applications, and grow into typed library design and large-scale engineering. Follow the roadmap one level at a time.

Learning path
8 levels · 8 practice projects
Start with JavaScript knowledge; no TypeScript experience is assumed.

This guide follows all 148 topics in typescript-mastery-roadmap.md, in their original order. Focus first on Levels 1–4 and the practical parts of Level 6 for frontend and React work.

Example baseline: TypeScript 5.9.3, strict checking, ES2022. This is a reproducible reference version, not a claim that it is the latest release. Each lesson is independent: do not paste all examples into one file. Browser examples need a DOM; React examples need React 19 and its types. Additional dependencies and setup are labeled. Classic Compiler API examples are specifically pinned to 5.9.3; newer compiler implementations can expose different APIs.

Read the explanation, adapt the example, then complete the practice project. Project code is a starting point; the acceptance checks describe the finished result. Type checking catches contract errors, while runtime tests verify behavior. Neither replaces the other.

Practical learning plan

  1. Phase 1 — Foundations (Weeks 1–3). Complete Level 1; practice DOM and events from Level 2; convert three small JavaScript components to TypeScript.
  2. Phase 2 — Reusable TypeScript (Weeks 4–6). Complete Levels 2 and 3; practice generics and utility types; rewrite your Tooltip library in TypeScript.
  3. Phase 3 — Application development (Weeks 7–10). Study Level 4 and practical parts of Level 6; learn Vite, strict tsconfig, linting, and testing; build a React + TypeScript application.
  4. Phase 4 — Advanced TypeScript (Weeks 11–16). Study Level 5; create custom utility types and typed abstractions; write declaration files and type tests.
  5. Phase 5 — Long-term expertise (Ongoing). Study Levels 7 and 8; publish and maintain a typed library; practice debugging complex types in production-sized projects.

The first 16 weeks assume regular study and practice. They are a suggested schedule, not a guarantee of mastery. Experience solving real problems develops expert judgment.

What expertise looks like

You can migrate unfamiliar JavaScript safely, model application states, design reusable abstractions, diagnose complex type errors, and maintain compatibility. Prefer the simplest types that provide the guarantees your application actually needs.

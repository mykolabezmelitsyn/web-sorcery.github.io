This guide preserves all 218 topic bullets in lottie-animation-mastery-roadmap.md. Review phases 1–3, build practical integrations in 4–8, then work through production concerns in 9–12. Phase 13 is optional specialization; phase 14 brings the skills together.

Reference versions: lottie-web 5.13.0 and @lottiefiles/dotlottie-web 0.81.0. They have different APIs. GSAP examples target 3.15.0; React examples use a 19.2 baseline and TypeScript 5.9.3. Pin tested versions and the lockfile; recheck advanced features when upgrading.

Running examples: use an ES-module Vite project served over HTTP. Copy named helper files from the indicated chapters. Place downloaded fixtures in public/animations/; root-relative paths in examples need the application’s base prefix on a subpath deployment. Code here is displayed and copied, never executed automatically.

One owner controls the playhead. Keep important status in HTML, gate commands on readiness, provide a static fallback, and destroy instances when their component is removed.
